# orographic_nwp_3d_downscaling test data

该目录用于存放气温地形降尺度（三维插值）算法的独立测试数据。

当前算法仓库仅保留最小配置模板和资源说明，完整业务流程仍依赖真实模式资料、地形数据、站点文件、实况数据、`Parameter/lib` 目录和二进制扩展运行环境。

后续建议补充最小端到端样例：

- 一组小范围模式输入资料。
- 对应的小范围地形或站点配置。
- 对应时次的实况资料。
- 期望输出结果或关键字段校验文件。
- 样例运行说明，包含 `work_dir`、`root_path`、`model_region`、`begin_date` 等参数。
